Embed

Two lines. That's the integration.

Copy mini-configurator.js and the exported product folder next to your page. The element sizes itself to its box, works on touch, and needs no build step. With a bundler, install the packages and keep one copy of Three.js.

  • Self-contained bundle: about 190 kB gzipped, Three.js included
  • npm packages with types for Vite, Next.js, Nuxt, Astro
  • Events for every change, quote and error; full API on the element
  • No accounts, no external requests, no tracking

FAQ

Questions, answered

Which model formats work?

glTF 2.0 and GLB, with or without DRACO or meshopt compression. Export from Blender, Cinema 4D, SketchUp, Fusion or any CAD tool. FBX, OBJ and STL convert to GLB in Blender in a minute.

Does it work with WordPress, Webflow, Shopify?

Anywhere you can add an HTML block and upload files. Upload the bundle and the product folder, paste the two lines. No plugin required.

Where do quote requests go?

To any URL you set: the included PHP script (mails you the request with the screenshot attached), the Node endpoint, a form service such as Formspree, or your own backend. The payload is plain JSON.

Is there a license check or telemetry?

No. The configurator makes no external requests. The license is a legal agreement: use it in unlimited projects, don't resell it as a configurator product.

Can I build my own UI?

Yes. The core package is the engine without a panel: load, configure, price, screenshot, quote. The web component is one UI on top of it.

What about AR, animations, USDZ?

Not in 1.0. The roadmap follows what buyers ask for; updates within 12 months are included.
