# Mini Configurator (archived)

This repository was a small code sample: a Three.js chair built from primitives, with the same
control panel in vanilla JS, React, Vue and Angular. It is archived and no longer maintained.

The finished product is **Mini Configurator Pro**: load any GLB, textures per option, optional
parts, live pricing, share links, a quote form with screenshot, React and Vue wrappers, and a
no-code Studio. Try the Studio in your browser with your own model:

**https://store.steildigital.nl**
